# Онлайн-игра «Бункер» (Bunker Web Game)

Веб-версия популярной настольной дискуссионной игры **«Бункер»**. Игроки получают случайные характеристики персонажей и должны убедить остальных, 
что именно они достойны места в спасительном убежище после глобальной катастрофы.

Проект работает в режиме реального времени (Real-Time) благодаря интеграции WebSocket-сервера.

---

## Стек технологий

*   **Frontend:** JavaScript (React.js, BrowserRouter), HTML5, CSS3, Sass
*   **Backend:** PHP 8.x + MySQL 
*   **Real-time сервер:** PHP Workerman (обработка игровых событий, ходов в реальном времени)

---

## Архитектура проекта

Проект разделен на три основные части:
1.  `/frontend` — клиентское React-приложение.
2.  `/backend` — REST API на PHP для авторизации, создания комнат и работы с БД MySQL.
3.  `/websocket` — сервер на базе Workerman для поддержания постоянного соединения и синхронизации игрового процесса между пользователями.

## Установка и запуск

### 1. Требования
Перед началом убедитесь, что у вас установлены:
*   Node.js (версии 16+) и npm
*   PHP (версии 8.0+) и `pdo_mysql`
*   СУБД MySQL

### 2. Клонирование репозитория
```bash
git clone https://github.com
cd bunker-game
```

### 3. Настройка и запуск Backend (с использованием AMPPS)

1. **Размещение проекта:** Перенесите содержимое папки `/Bunker_BackEnd` (или всего проекта) в корневую директорию веб-сервера AMPPS (обычно это папка `AMPPS/www/`).
2. **База данных:** Откройте **phpMyAdmin** через интерфейс AMPPS, создайте базу данных `bunker_db` и импортируйте в неё файл `database.sql`.
3. **Запуск веб-сервера:** Убедитесь, что в панели AMPPS включены (состояние **Running**) сервисы **Apache** и **MySQL**.
4. **Запуск WebSocket-сервера (Workerman):** 
   Поскольку Workerman работает как самостоятельный демон, его необходимо запустить через терминал/командную строку с помощью установленного в AMPPS интерпретатора PHP:
   ```bash
   cd path/to/bunker-game/websocket
   php start.php start
   ```
   *(Примечание для Windows: Если команда `php` не распознается,
   укажите полный путь к исполняемому файлу PHP из папки AMPPS, например: `C:\Program Files\Ampps\php-8.2\php.exe start.php start`)*
4. Запустите сервер **Workerman** (из папки WebSocket-сервера):
   ```bash
   cd ../workerman_server
   php start.php start -d
   ```
   *Флаг `-d` запускает сервер в режиме демона (в фоне). Для тестирования можно запустить без него: `php start.php start`.*

### 5. Настройка и запуск Frontend
1. Перейдите в папку фронтенда:
   ```bash
   cd ../Bunker
   ```
2. Установите npm-пакеты:
   ```bash
   npm install
   ```
3. Создайте файл `.env` в корне папки `Bunker` и укажите адреса API и WebSocket сервера:
   ```env
   REACT_APP_API_URL=http://localhost/bunker/backend
   REACT_APP_WS_URL=ws://localhost:2346
   ```
4. Запустите проект в режиме разработки:
   ```bash
   cd 'Bunker Online'
   npm start
   ```
5. Откройте (http://localhost/Bunker/reg.php) в браузере.

## Игровой процесс (Геймплей)

1.  **Создание комнаты:** Один из игроков создает лобби и делится кодом комнаты с друзьями.
2.  **Генерация карт:** После старта игры каждому игроку сервер генерирует случайный набор характеристик (Профессия, Здоровье, Хобби, Фобия, Багаж, Факт).
3.  **Раунды открытия:** Игроки по очереди открывают свои характеристики и аргументируют свою полезность для бункера.
4.  **Голосование:** В конце каждого раунда через WebSocket проходит синхронное голосование. Игрок, набравший больше всего голосов, изгоняется.
5.  **Финал:** Игра завершается, когда в бункере остается заданное правилами количество человек.
